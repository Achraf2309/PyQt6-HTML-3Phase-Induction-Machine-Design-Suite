# PyQt6-HTML-3Phase-Induction-Machine-Design-Suite
Suite d'applications (PyQt6 &amp; HTML/JS) pour le dimensionnement analytique et la visualisation 2D/3D d'une machine asynchrone triphasée à cage d'écureuil.  EN : Comprehensive design suite (PyQt6 &amp; HTML/JS) for analytical sizing and 2D/3D interactive visualization of 3-phase squirrel-cage induction machines.
